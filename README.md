# 🛍 Telegram-бот магазина мужской одежды

Бот на **aiogram 3 + SQLAlchemy 2.0 (SQLite)**. Клиент видит каталог, подбирает размер и оформляет заказ. Владелец управляет товарами через пошаговую кнопочную админ-панель прямо в Telegram.

---

## 🚀 Установка (по шагам)

### 1. Установите Python 3.11+
Проверьте версию:
```bash
python --version
```

### 2. Установите зависимости
В папке проекта выполните:
```bash
pip install -r requirements.txt
```

### 3. Создайте файл `.env`
Скопируйте шаблон:
```bash
# Windows PowerShell
Copy-Item .env.example .env
```
Откройте `.env` любым текстовым редактором и заполните:
- `BOT_TOKEN` — токен бота от [@BotFather](https://t.me/BotFather)
- `ADMIN_IDS` — ваш цифровой Telegram ID (узнать у [@userinfobot](https://t.me/userinfobot)). Если админов несколько — через запятую: `123456789,987654321`
- `CURRENCY` — валюта цен (например: `сом`, `₽`, `$`)

Пример заполненного `.env`:
```
BOT_TOKEN=7890123456:AAF...ВашТокен
ADMIN_IDS=123456789
CURRENCY=сом
DELIVERY_MIN_DAYS=18
DELIVERY_MAX_DAYS=25
DB_NAME=shop.db
```

### 4. Запустите бота
```bash
python bot.py
```
База данных `shop.db` создастся автоматически при первом запуске.

## 👤 Для клиента
- **👔 Каталог одежды** — выбор категории открывает **фото-галерею**: фото + цена + доставка одним сообщением, листайте товары кнопками ◀️ ▶️, фото внутри карточки — кнопкой 📷. Есть и текстовый вид («📝 Списком»).
- **📐 Подбор размера** — бот спросит рост и вес, подберёт размер по размерной сетке.
- **🚚 Доставка и оплаты** — срок доставки (18–25 дней) и условия.
- **🛒 Корзина** — добавить товары и оформить заказ.
- **💬 Связь с менеджером** — контакт для связи.

---

## 🖼 Фото в каталоге
Каталог показывает фото сразу в карточке (одно сообщение: фото + подпись + кнопки).
Для демо-товаров фото можно сгенерировать и загрузить одной командой:
```bash
python upload_photos.py            # только товары без фото
python upload_photos.py --force    # перегенерировать все фото
```
Скрипт отправит плашки с названиями вам в Telegram и сохранит `file_id` в БД.
Настоящие фотографии загружайте через админ-панель: **➕/📦 → 📷 Фото**.

## ⚙️ Для владельца (админ-панель)
Откройте командой `/admin` или кнопкой **⚙️ Админ-панель** (видна только админам).

- **➕ Добавить товар** — пошаговый мастер из 6 шагов:
  1. Категория → 2. Название → 3. Фото (1+) → 4. Цена → 5. Доставка → 6. Шаблон замеров.
  На шаге 6 бот присылает готовый текст — просто скопируйте и замените значения.
- **📦 Список товаров** — изменить цену/доставку или удалить.
- **🗂 Управление категориями** — добавить/удалить.
- **📥 Заказы** — входящие заказы с контактами и адресом, подтверждение.
- **🚚 Настройки доставки** — изменить срок доставки кнопками (сохраняется).

При новом заказе админ получает уведление в личные сообщения.

## 🗂 Структура проекта
```
puwkin/
├── bot.py                 # точка входа
├── config.py              # настройки из .env
├── states.py              # FSM-состояния
├── upload_photos.py       # демо-фото каталога (Pillow → file_id в БД)
├── database/
│   ├── db.py              # движок SQLAlchemy
│   ├── models.py          # таблицы БД
│   └── settings_store.py  # настройки магазина
├── handlers/              # user, catalog, size_helper, cart, admin
├── keyboards/             # inline.py, reply.py
└── utils/size_parser.py   # подбор размера
```

## 🔒 Примечание
Срок доставки и любые тексты для клиента настраиваются в одном месте. Названия стран-поставщиков в боте не используются.
