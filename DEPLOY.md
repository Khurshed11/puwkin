# 🚀 Развёртывание: GitHub + бот 24/7

Схема: **публичный репозиторий с кодом** + **приватный репозиторий только для
`shop.db`** + **GitHub Actions**, который держит бота запущенным круглосуточно.

Как это работает:
- каждую минуту запускается workflow; пока один экземпляр бота работает (~5 ч
  50 мин), второй стоит в очереди и стартует сразу после — простоя ~40–60 секунд
  каждые ~6 часов;
- Telegram держит входящие сообщения в очереди, пока бота нет, — клиенты ничего
  не теряют;
- в конце каждой сессии `shop.db` коммитится в приватный репозиторий, при старте
  — загружается обратно. Заказы и фото остаются на месте.

## Шаг 1. Создайте два репозитория
На [github.com](https://github.com/new):

| Репозиторий | Тип | Пример имени |
|---|---|---|
| Код бота | **Public** (иначе бесплатные минуты Actions закончатся за день) | `puwkin` |
| Только БД | **Private** | `puwkin-shop-db` |

Пустые репозитории, без README.

## Шаг 2. Токен доступа
1. [github.com/settings/tokens](https://github.com/settings/tokens) →
   **Generate new token (classic)**.
2. Срок — например, 90 дней (потом обновите).
3. Галочки: **repo** и **workflow**.
4. Скопируйте токен — он понадобится для пуша и как секрет `DB_TOKEN`.

## Шаг 3. Публикация кода
Команды пуша (из папки проекта):

```powershell
git remote add origin https://github.com/ВАШ_НИК/puwkin.git
git push -u origin main
```

При запросе логина/пароля вставьте токен вместо пароля.
В репозиторий не попадут `.env` и `shop.db` — их отсеивает `.gitignore`.

## Шаг 4. Первичная загрузка БД
Скопируйте текущую `shop.db` в приватный репозиторий БД:

```powershell
git clone https://github.com/ВАШ_НИК/puwkin-shop-db.git "$env:TEMP\shopdb"
Copy-Item shop.db "$env:TEMP\shopdb\shop.db"
cd "$env:TEMP\shopdb"
git add shop.db
git commit -m "initial db"
git push
```

## Шаг 5. Секреты в публичном репозитории
В репозитории с кодом: **Settings → Secrets and variables → Actions → New
repository secret**. Создайте:

| Секрет | Значение |
|---|---|
| `BOT_TOKEN` | токен бота из `.env` |
| `ADMIN_IDS` | `5992735243` |
| `MANAGER_USERNAME` | `@khurrshed1` |
| `CURRENCY` | `сом` |
| `DB_TOKEN` | токен из шага 2 |
| `DB_REPO` | `ВАШ_НИК/puwkin-shop-db` |

## Шаг 6. Включите Actions
Вкладка **Actions** в репозитории → **I understand my workflows, go ahead and
enable them**. Бот стартует в течение минуты. Проверка: напишите ему в личные
сообщения.

## ⚠️ Важно
- **Не запускайте бота локально, пока он работает на GitHub** — два экземпляра
  конфликтуют (ошибка 409) и Telegram начнёт отдавать обновления только одному.
- Лимит Actions: ~43 000 минут/мес — это бесплатно **только для публичных
  репозиториев**. В приватном репозитории бесплатны 2000 минут/мес — боту не хватит.
- GitHub формально не приветствует «постоянно включённые» раннеры: в редких
  случаях платформа может ограничить такое использование. Надёжная альтернатива —
  дешёвый VPS (TimeWeb Cloud ~200 ₽/мес), бот там крутится без перезапусков.
- Токен (шаг 2) имеет доступ к обоим репозиториям — не публикуйте его и
  ротируйте по истечении срока.
